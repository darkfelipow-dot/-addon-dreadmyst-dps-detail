Hi, felipow here.

To use the "Addon" or DPS details, you need to install the NPCAP tool.

https://npcap.com
It's a tool for listening to network traffic; it's the same system used by some FF14 addons.

You must select the network card you're connected to the internet through. (Open Command Prompt and run "ipconfig /all".)

If you can't find the correct network card, restart the program until you select it.
